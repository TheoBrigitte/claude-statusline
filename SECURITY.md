# Security Policy

## Supported Versions

Only the following versions of claude-statusline are supported. If you find a security issue with an older version, please try updating to the latest version first.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

If for some reason you can't update to the latest version, please let us know your reasons so that we can have a better understanding of your situation.

## Reporting a Vulnerability

If you discover a vulnerability in this project, please help us handle it responsibly by following these steps:

1. **Do not disclose the vulnerability publicly.**
2. Contact us directly by creating a new security report describing your discovery via: https://github.com/TheoBrigitte/claude-statusline/security/advisories

Thank you for your help in keeping this project secure!
